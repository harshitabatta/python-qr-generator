# QR Code Generator 🧾

A simple QR Code Generator built using **Python** as a 1st-semester mini project. The application features a graphical user interface that allows users to enter text or a URL and generate a QR code with a click.

## 📌 About the Project

This project was developed as part of our **1st Semester Python Mini Project**. The objective was to create a QR code generator using Python and provide a simple graphical interface for interacting with it.

The application allows users to enter text or a website URL and generate its corresponding QR code through a GUI.

## ✨ Features

- **QR Code Generation:** Generate QR codes from text or URLs.
- **Graphical User Interface:** Simple interface built using Tkinter.
- **Easy to Use:** Enter content and generate a QR code with a single click.
- **Menu Options:** Includes File and Help menus.
- **Simple & Lightweight:** Built using Python libraries.

## 🛠️ Tech Stack

- **Programming Language:** Python
- **GUI:** Tkinter
- **QR Code Generation:** PyQRCode
- **IDE:** Visual Studio Code

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Required Python libraries

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/python-qr-generator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-qr-generator
   ```

3. Install the required library:

   ```bash
   pip install pyqrcode
   ```

4. Run the application:

   ```bash
   python qr_generator.py
   ```

> Replace `qr_generator.py` with the actual Python filename if it differs.

## 💻 How It Works

1. Launch the application.
2. Enter text or a URL into the input field.
3. Click the **Create** button.
4. The application generates and displays the corresponding QR code.
